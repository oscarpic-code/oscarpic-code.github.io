## 📁 Estructura del Proyecto

* **`index.html`** — Estructura principal de la web (CV / Portfolio).
* **`clientes.html`** — Sección dedicada a proyectos y clientes corporativos.
* **`colaboradores.html`** — Sección para alianzas, contribuciones y equipo.
* **`css/`** — Hoja de estilos (`styles.css`) y diseño visual.
* **`js/`** — Lógica y datos dinámicos:
  * `data.js` — Base de datos del contenido y perfil.
  * `app.js` — Funcionalidades interactivas y motor de búsqueda.
* **`img/`** — Recursos visuales y favicon.
* **`sitemap.xml`** / **`googlec...html`** — Archivos de SEO y verificación de Search Console.
